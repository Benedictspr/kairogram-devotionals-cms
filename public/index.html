Live API Endpoints

Kairogram mobile app automatically connects to this cloud feed with zero user input. All endpoints support standard CORS (*).

GET /api/devotionals/latest

Fetches the complete active catalog (publications, dates, and Sunday school lessons) consumed directly by Kairogram zero-tap sync.

GET /api/devotionals?date=YYYY-MM-DD

Retrieves all devotional editions published for a specific date (e.g. 2026-09-20).

GET /api/devotionals?church=rccg

Filters library entries for a specific church (rccg, dclm, mfm, christ_embassy, odm, dunamis, winners).

POST /api/devotionals

Publishes a single devotional object or an array of devotionals to the cloud database.

Kairogram Sync Mechanism

⚡ Zero-Tap Real-Time Updates

1. Whenever you tap Publish in this studio, the entry is immediately stored in the cloud API and broadcasted across active browser tabs.
2. The Kairogram mobile app automatically checks for cloud updates on launch, whenever you open the Devotionals tab, and whenever the device regains Internet connectivity.
3. If you want permanent GitHub persistence for all CMS updates on serverless reboots, add GITHUB_TOKEN and GITHUB_REPO in your Vercel project environment variables.
